# 诗词赏析与个人注本（poem-annotation）

## ADDED Requirements

### Requirement: L1 点句即释
阅读页中任意诗句 SHALL 可点击，行内浮出该句的白话直译与关键词注（词/短语级解释数组）。内容由 LLM 按「全文为上下文 + 目标句」生成，结果 MUST 按诗 id + 行索引缓存至注本；再次点击同一句直接读取缓存，MUST NOT 重复请求。

#### Scenario: 点击诗句浮出逐句注
- **WHEN** 用户点击正文任意一行
- **THEN** 该行下方浮出直译与关键词注，且数据来自一次 LLM 调用

#### Scenario: 二次点击命中缓存
- **WHEN** 关闭浮层后再次点击同一行
- **THEN** 直接展示已缓存内容，不发起新的 LLM 调用

### Requirement: L2 结构化赏析
赏析视图 SHALL 呈现分节结构化内容：大意、炼字手法条目数组、意境，以及带不确定性标记的创作背景。生成结果永久缓存于注本；用户主动点击「重新生成」时 MUST 先经确认（若该条已被用户编辑则双重确认）。

#### Scenario: 首次打开赏析页签触发生成并缓存
- **WHEN** 用户首次切换到某诗的「赏析」页签
- **THEN** 发起一次整篇结构化生成，完成后渲染各节并写入注本

#### Scenario: 再次打开直接读取缓存
- **WHEN** 已有缓存的诗再次打开赏析页签
- **THEN** 立即渲染缓存内容，不发起 LLM 调用

### Requirement: 幻觉护栏
生成 prompt MUST 包含护栏条款：仅基于给定文本做艺术分析；创作背景与典故溯源必须使用「相传/一般认为」等措辞或标记不确定；无把握的信息留空。背景字段 SHALL 携带 uncertain 标记并在 UI 上可视化呈现。

#### Scenario: 背景不确定性可视化
- **WHEN** 赏析中的背景节被模型标记为不确定
- **THEN** UI 在该节显著位置展示「史料不详，仅供参考」类标识

### Requirement: 个人注本为用户资产
注本列表 SHALL 按 poem 维度聚合展示全部条目（逐句注/赏析/对话轮）。每条 SHALL 支持编辑：编辑后条目标记 user_edited，后续再生成流程 MUST 先经用户确认方可覆盖；删除 MUST 二次确认。

#### Scenario: 编辑后的条目受保护
- **WHEN** 用户手动编辑某条逐句注后点击该条的重新生成
- **THEN** 弹出确认对话框说明将覆盖手写内容，取消则不做任何变更

#### Scenario: 注本按更新时间倒序
- **WHEN** 打开注本列表
- **THEN** 条目按 updated_at 从新到旧排列

### Requirement: 人格系统作用于 AI 内容
应用 SHALL 内置先生/知音/词客三套人格模板（随安装包分发），默认知音；用户可在设置中选择，选择结果作用于此后所有新生成的 AI 内容。人格 MUST NOT 影响 UI 文案。每条注本记录 SHALL 记录生成时的人格。

#### Scenario: 切换人格后新生成内容的语气变化
- **WHEN** 用户从知音切换到先生后重新生成一首诗的赏析
- **THEN** 新内容语气符合先生人格设定，而既有条目保持原样
