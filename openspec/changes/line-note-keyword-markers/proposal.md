## Why

L1 逐句即释目前只在底部抽屉中以普通文本列出关键词注，用户无法从诗句本身发现这些关键词，也看不到拼音。对不熟悉古汉语或生字的读者来说，关键词解释缺少原文定位和读音，学习路径不完整。

## What Changes

- 为 L1 关键词注增加可选拼音字段，并要求新生成结果返回带声调拼音。
- 关键词注生成成功后，在对应诗句中的实际词语上显示可点击标记。
- 点击关键词标记复用词语解释面板，展示词语、拼音和解释。
- 读取已有 L1 缓存时也恢复关键词标记；旧缓存无拼音时继续兼容。
- 保持整行点击打开逐句注的能力，未命中关键词的区域仍可打开 L1 抽屉。

## Non-goals

- 不改变 L1 的缓存键和注本表结构。
- 不实现本地拼音词典或自动纠正模型返回的拼音。
- 不把关键词解释上传到 Worker/R2。
- 不改变 L2 自动词注、用户选词解释和诗文原文。

## Capabilities

### New Capabilities

- None.

### Modified Capabilities

- `poem-annotation`: L1 关键词注增加拼音及原文高亮/点击联动。

## Impact

- `KeywordNote` 领域模型、L1 Prompt/JSON 解析。
- 阅读页状态与关键词标记渲染。
- 逐句注抽屉和词语解释面板。
- 新增缓存恢复、拼音显示和关键词点击测试；无需数据库迁移或第三方依赖。
