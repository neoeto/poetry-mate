## Requirements
### Requirement: L1 点句即释
阅读页中任意诗句 SHALL 可点击，行内浮出该句的白话直译与关键词注（词/短语级解释数组）。关键词注 SHALL 可包含对应拼音；有有效关键词注的词语 MUST 在对应诗句原文中显示可点击标记，点击后展示词语、拼音和解释。内容由 LLM 按「全文为上下文 + 目标句」生成，结果 MUST 按诗 id + 行索引缓存至注本；再次点击同一句直接读取缓存，MUST NOT 重复请求。

#### Scenario: 点击诗句浮出逐句注
- **WHEN** 用户点击正文任意一行
- **THEN** 该行下方浮出直译与关键词注，关键词注中的非空拼音一并显示

#### Scenario: 关键词在原文中高亮并可点击
- **WHEN** L1 结果包含正文中实际出现的关键词
- **THEN** 对应词语在诗句中显示标记，点击后展示该词语的拼音和解释

#### Scenario: 二次点击命中缓存
- **WHEN** 关闭浮层后再次点击同一行
- **THEN** 直接展示已缓存内容，不发起新的 LLM 调用，且已有关键词标记继续存在

#### Scenario: 旧关键词缓存缺少拼音
- **WHEN** 已有 L1 缓存的关键词只有 term 和 explain，没有 pinyin
- **THEN** 应用正常展示关键词解释并保留原文标记，不崩溃、不显示错误拼音

### Requirement: L2 结构化赏析
赏析视图 SHALL 呈现分节结构化内容：大意、炼字手法条目数组、意境，以及带不确定性标记的创作背景。首次生成（缓存未命中或用户主动重新生成）SHALL 以流式方式渐进呈现：各节在其字段完整闭合后依生成顺序出现，未生成节显示进行中占位而非「模型未提供此部分内容」文案；编辑与重新生成入口 SHALL 在生成完成后出现。生成结果永久缓存于注本；用户主动点击「重新生成」时 MUST 先经确认（若该条已被用户编辑则双重确认）。

#### Scenario: 首次打开赏析页签触发生成并缓存
- **WHEN** 用户首次切换到某诗的「赏析」页签
- **THEN** 发起一次整篇结构化生成，完成后渲染各节并写入注本

#### Scenario: 赏析各节渐进呈现
- **WHEN** 整篇赏析流式生成进行中
- **THEN** 已闭合的节（如大意）先于后续节渲染，期间不显示残缺 JSON 文本，原文下划线标记仅在生成完成后出现

#### Scenario: 再次打开直接读取缓存
- **WHEN** 已有缓存的诗再次打开赏析页签
- **THEN** 立即渲染缓存内容，不发起 LLM 调用

### Requirement: 幻觉护栏
生成 prompt MUST 包含护栏条款：仅基于给定文本做艺术分析；创作背景与典故溯源必须使用「相传/一般认为」等措辞或标记不确定；无把握的信息留空。背景字段 SHALL 携带 uncertain 标记并在 UI 上可视化呈现。

#### Scenario: 背景不确定性可视化
- **WHEN** 赏析中的背景节被模型标记为不确定
- **THEN** UI 在该节显著位置展示「史料不详，仅供参考」类标识

### Requirement: 个人注本为用户资产
注本列表 SHALL 按 poem 维度聚合展示全部条目（逐句注/赏析/对话轮）。每条 SHALL 支持编辑：编辑后条目标记 user_edited，后续再生成流程 MUST 先经用户确认方可覆盖；删除 MUST 二次确认。

#### Scenario: 编辑后的条目受保护
- **WHEN** 用户手动编辑某条逐句注后点击该条的重新生成
- **THEN** 弹出确认对话框说明将覆盖手写内容，取消则不做任何变更

#### Scenario: 注本按更新时间倒序
- **WHEN** 打开注本列表
- **THEN** 条目按 updated_at 从新到旧排列

### Requirement: 人格系统作用于 AI 内容
应用 SHALL 内置先生/知音/词客三套人格模板（随安装包分发），默认知音；用户可在设置中选择，选择结果作用于此后所有新生成的 AI 内容。人格 MUST NOT 影响 UI 文案。每条注本记录 SHALL 记录生成时的人格。

#### Scenario: 切换人格后新生成内容的语气变化
- **WHEN** 用户从知音切换到先生后重新生成一首诗的赏析
- **THEN** 新内容语气符合先生人格设定，而既有条目保持原样

### Requirement: L2 词语解释与原文联动
整篇赏析 SHALL 可返回若干个诗文中实际出现的词语、对应拼音及解释。拼音 SHOULD 使用结合语境的标准汉语拼音并带声调；解释条目 SHOULD 带有正文零基行号。应用 MUST 仅为正文中精确命中的词语显示下划线提示，点击后展示对应词语、拼音和解释。旧版没有词语解释或拼音字段的赏析缓存仍 SHALL 正常展示。

#### Scenario: 赏析词语在原文中可点击
- **WHEN** 用户完成一首诗的整篇赏析，且结果包含诗文中的词语、拼音和解释
- **THEN** 原文页对应词语显示可点击提示，点击后展示词语、拼音和解释

#### Scenario: 旧缓存缺少拼音
- **WHEN** 已有赏析缓存包含词语和解释但没有 pinyin 字段
- **THEN** 应用正常展示词语和解释，不崩溃、不显示错误读音，并允许后续重新生成补全

#### Scenario: 模型返回诗文外词语
- **WHEN** 赏析结果中的词语不在诗文正文中
- **THEN** 应用不为该词语添加原文标记

### Requirement: 解析流式编排与降级
L1/L2 的首次生成 SHALL 以流式方式编排：增量内容以「部分 JSON 解析后的已闭合字段快照」事件对外发布，MUST NOT 呈现未闭合的残缺文本；每次重试轮次开始时 MUST 先通知调用方重置已显示的增量内容。流式传输失败或流内容为空时 SHALL 自动降级为一次性非流式补全，降级结果 MUST 替换而非叠加已显示的增量内容；结构化解析失败 SHALL 沿用「重试一次（附格式纠正提示）→ 模型原文纯文本降级」路径。护栏校验（诗文外词过滤、选区一致性）与注本写入 MUST 仅基于流结束后的完整结果执行。调用方关闭浮层或离开页面时 MUST 取消流式订阅。

#### Scenario: 流式中断自动降级
- **WHEN** L1/L2 流式生成过程中传输中断或流内容为空
- **THEN** 服务自动改用一次性非流式补全完成生成，已显示的增量内容被完整结果替换，不出现重复文本

#### Scenario: 解析失败重试与纯文本降级
- **WHEN** 流式拼接后的全文两次均无法解析为合法 JSON
- **THEN** 抛出携带模型原文的格式异常，UI 展示纯文本降级内容

#### Scenario: 关闭浮层取消订阅
- **WHEN** L1/L2 正在流式生成时用户关闭底部浮层
- **THEN** 流式订阅被取消，不再向 UI 发布增量，也不写入注本

#### Scenario: 落库仅使用完整结果
- **WHEN** L2 流式生成完成
- **THEN** 仅流结束后的完整结果经诗文外词过滤后写入注本，流式中间态不出现在注本中

### Requirement: 用户选择词语发起 AI 解释
阅读页 SHALL 支持用户在同一句正文中选择一个字、词或短语，并从系统文本选择菜单发起“AI 解释”。请求 MUST 通过用户已配置的 LLM，携带全诗正文、所在行和原文选区；没有 API Key 时 SHALL 展示配置引导而不是修改诗文或产生错误堆栈。跨行选择 SHALL 提示用户在同一句中选择，不得发起请求。用户选词解释结果 SHALL 包含所选词语的拼音（若模型无法可靠判断，字段可为空）。

#### Scenario: 选择同一句中的词语并请求解释
- **WHEN** 用户长按或拖动选中正文同一句中的“孤”字，并点击“AI 解释”
- **THEN** 应用使用全诗、所在行和“孤”字作为上下文发起一次结构化 LLM 请求，并在结果中展示拼音（若返回）

#### Scenario: 无 Key 时选择词语
- **WHEN** 用户选中词语并点击“AI 解释”，但尚未配置 API Key
- **THEN** 应用展示“还没有配置 AI”及设置入口，不写入注本且原文保持不变

#### Scenario: 选择范围跨越两句
- **WHEN** 用户选择范围同时包含两句正文
- **THEN** 应用提示“请在同一句中选择”，不发起 LLM 请求

### Requirement: 用户词语解释本地缓存与原文标记
成功的用户词语解释 SHALL 作为个人注本中的独立条目保存在 APP 本地，并包含原文词语、拼音（可为空）、解释、所在行、选区位置、来源和不确定性状态。应用 MUST 仅在原文精确命中时显示下划线标记；再次打开同一位置 SHALL 优先读取缓存，不重复请求。用户词语解释与 L2 自动词语解释 SHALL 可以同时存在。

#### Scenario: 成功解释后标记原文
- **WHEN** LLM 返回所选词语的有效解释和拼音
- **THEN** 应用保存本地注本条目，并在对应原文范围显示可点击的点状下划线，面板显示拼音

#### Scenario: 再次选择同一位置
- **WHEN** 用户再次选择同一句中相同起止位置的词语并点击“AI 解释”
- **THEN** 应用展示本地缓存解释和拼音且不发起新的网络请求

#### Scenario: 模型返回无法匹配原文的词语
- **WHEN** LLM 返回的词语或位置与用户选中的原文不一致
- **THEN** 应用不创建原文标记或半成品注本，并展示可重试的格式/匹配错误

### Requirement: 用户词语解释可查看、编辑和安全重生成
用户点击用户词语标记 SHALL 打开解释面板，展示词语、解释、来源和不确定性提示；该条目 SHALL 支持编辑、删除和重新生成。编辑后重新生成 MUST 先确认覆盖，且手写内容 MUST 经过二次确认后才可覆盖。

#### Scenario: 点击用户词语标记查看解释
- **WHEN** 用户点击原文中带下划线的用户词语
- **THEN** 应用打开解释面板，显示该词语的解释并标明“我选的词”来源

#### Scenario: 编辑后的用户解释受保护
- **WHEN** 用户编辑用户词语解释后点击“重新生成”并取消覆盖确认
- **THEN** 原解释保持不变，不发起覆盖写入

#### Scenario: 不确定性提示
- **WHEN** LLM 将用户词语解释标记为不确定
- **THEN** 解释面板显著展示“仅供参考”类提示
